Hokusai layer generator

Renders every layer of the print to its own PNG and PUTs it into assets/img/art/hokusai/. Re-run after changing a layer's drawing code. Full-frame layers are all 2000×1250 and aligned, so they stack as one document.

A plain static server has nowhere to put the files, so run python3 tools/layerserve.py from the repository root and open this page at http://127.0.0.1:4188/tools/hokusai-layers.html. Opened any other way it still renders every layer below — the writes just fail.
